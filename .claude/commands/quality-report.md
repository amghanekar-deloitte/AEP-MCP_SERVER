# Quality Report

View Stage 0 quality scoring and ERD outputs, or re-run Stage 0 analysis.

## When to Use
- Reviewing the data quality report generated by Stage 0 (`data-analyst`)
- Reviewing the Mermaid ERD from Stage 0
- Re-running Stage 0 analysis after data remediation
- Checking go/no-go ingestion readiness before Stage 6

## Usage
```
/quality-report
/quality-report Sampledata/
/quality-report <description of what to review>
```

## Note on Stage Placement
Quality scoring and ERD generation are both **Stage 0** outputs produced by the `data-analyst` agent.
They are NOT separate pipeline stages.

## Workflow

### 1. Check Existing Outputs
- Look for existing outputs in `Result_DataAnalysis/`:
  - `quality_summary.csv` — overall quality score per entity
  - `quality_fields.csv` — per-field quality metrics
  - `quality_issues.csv` — issues with severity and recommendations
  - `erd_data_model.md` — Mermaid ERD
- If outputs exist, display the quality summary and ERD directly

### 2. Re-run Stage 0 (if requested or outputs missing)
Route to `data-analyst` agent to re-run Stage 0:
- Profile CSV files in `Sampledata/` (or provided path)
- Score quality across 6 dimensions
- Generate Mermaid ERD
- Overwrite existing outputs in `Result_DataAnalysis/`

### 3. Ingestion Readiness
- Overall score ≥ 80 (Good/Excellent): proceed with ingestion
- Overall score 60–79 (Fair): review issues, proceed with caution
- Overall score < 60 (Poor/Critical): remediate data before ingestion
